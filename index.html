about

From a closed board to an open one.

Most of what I know I picked up by building something, getting it wrong, and figuring out why. A Reversi engine taught me game logic. A school seminar site taught me the web. Every repo is a checkpoint.

Reversi has 64 squares and two colors. It's a good place to learn how logic works — but it's also a closed system: fixed board, fixed rules, no sensors, no signal from the outside world. At some point I wanted to build things that didn't just compute a move, but actually watched, measured, and responded to something real.

That's what I'm building now with my fitness dashboard — currently in progress, so there's nothing to click through yet, but the shape of it is set. A React frontend will talk to a REST API, which talks to a Raspberry Pi, which talks to hardware I'm building myself. Every layer is something I'm learning by breaking it first: the frontend is teaching me state and interaction, the API is teaching me how systems actually talk to each other, and the Pi and sensors will teach me that code eventually has to survive contact with the physical world.

It's designed to keep growing. Every new thing I learn — a new sensor, a new ML model, a cleaner API pattern — will have a place to plug in. Instead of stacking finished checkpoints next to each other, this one project is meant to absorb them as it goes. If Reversi was a closed board with a fixed set of moves, this is the opposite: an open board I'm still setting up, with room for every piece I haven't learned to play yet.
