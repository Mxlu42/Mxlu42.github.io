How this site got built.

This portfolio wasn't hand-typed alone - and it wasn't blindly “generated” either. I built it with Claude Code as a pair: I set the direction and made every call, and the AI handled the scaffolding, caught my mistakes, and pushed the design past its defaults. Here's the actual workflow, honestly.

the workflowfig. 01 - workflow

Six moves, in order.

Filled discs - these already happened. Each step used a specific Claude Code capability.

  1. Plan before writing code

    We started in planning mode. Claude explored the repo, asked me pointed questions about stack, sections, and visual direction, then wrote a plan file I reviewed and approved - before a single line was written.

    /planAskUserQuestionplan file → approval

  2. Install a skill for taste, not just code

    My first draft looked like generic AI output - dark background, gradient accent, meaningless 01/02/03 markers. So I installed Anthropic's official frontend-design skill. It reframed the brief: stop shipping defaults, build an identity specific to me. For this redesign, I reached for the same habit again - frontend-design for direction, plus a new impeccable skill this round for critique and polish. Iteration two, not a new trick.

    Skill: frontend-designSkill: impeccable

  3. Ground the design in my own work

    The site's identity - the interactive Reversi board - comes straight from my flagship repo, and it's not just a coat of paint: the board runs my actual engine, ported 1:1 from Python (Reversi.py) into browser JavaScript. Palette, typography, motion, and the game logic all derive from that one honest idea instead of a template.

    design systemReversi.py1:1 port (Python → JS)

  4. Structural code awareness (MCP)

    The project is wired to an MCP server - a knowledge graph that maps the codebase structure for token-efficient review and impact analysis, so changes are understood in context rather than by re-reading everything.

    MCP: code-review-graph

  5. Memory that persists

    Claude Code saved durable notes - my design preferences and project context - to a persistent memory. The next session starts already knowing how I like to work.

    Memory

  6. Verify, then iterate

    The engine port wasn't eyeballed - it was proven. I replayed 726 steps of my real Python engine through the JavaScript version and diffed every board: zero mismatches, plus a full game matching Python end to end. Ordinary changes got the same treatment: JS syntax with node --check, a local server plus curl status checks, and link validation. Then refined piece by piece - reordering the roadmap, wiring in my resume.

    parity: 726 stepsengine-trace diffnode --checkhttp.servercurl

the toolkitfig. 02 - toolkit

What each piece actually does.

planning

Plan mode

Research and questions first, an approved plan second, code third. It stops the AI from sprinting in the wrong direction.

skills

Skills

Packaged expertise you drop in on demand - here, a design skill that raised the bar on aesthetics and killed the templated look, reused (with a critique-focused sibling skill) for this redesign's pass.

context

MCP

A protocol that connects the AI to real tools and data - in this case a live graph of the codebase's structure.

continuity

Memory

Facts that survive between sessions, so preferences and project context don't have to be re-explained every time.

trust

Verification loop

Nothing ships on a hunch. Syntax checks, a running server, and status codes prove each change before we move on.

human in the loopfig. 03 - process

What the AI accelerated

  • Scaffolding the HTML, CSS, and JS fast, with a consistent system.
  • Catching broken links and bugs before I ever saw them.
  • Exploring options quickly so I could react, not start from a blank page.
  • Doing the tedious verification on every change.

What I decided

  • The brief - what this site is and who it's for.
  • The concept - the Reversi identity was mine to choose.
  • What's true vs. hype - this page is honest on purpose.
  • Content, priorities, and final sign-off on every step.

AI didn't replace the decisions.
It made room for me to make more of them.
